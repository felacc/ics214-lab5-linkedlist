# Dynamically Allocated Linked List
In this lab, I created a dynamically allocated linked list to practice using pointers in C++. This lab was extremely valuable for learning about working with pointers, references, and dynamic memory allocation.

## Lab Learning Objectives
1. Use pointers to create, view, and delete entries in a linked list.
2. Use dynamic memory allocation and de-allocation for each node in the list.
3. Add const to function parameters when appropriate.
